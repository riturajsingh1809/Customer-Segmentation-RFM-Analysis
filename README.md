# Customer Segmentation – RFM Analysis

*Developed by Ritu Raj Singh*

## Project Overview

This project focuses on *Customer Segmentation using RFM Analysis* to identify and classify customers based on their purchasing behaviour.

RFM stands for:

* *Recency* – How recently a customer purchased
* *Frequency* – How frequently a customer purchased
* *Monetary* – How much a customer spent

## Tools Used

* *Excel* – Data cleaning and initial data preparation
* *Python (Pandas, NumPy)* – RFM analysis and customer segmentation
* *Tableau* – Data visualization and interactive dashboard
* *GitHub* – Project documentation and version control

## Project Workflow

Excel Data → Data Cleaning → Python RFM Analysis → Customer Segmentation → Tableau Dashboard

## Key Analysis

The project calculates RFM scores and classifies customers into segments such as:

* Champions
* Loyal Customers
* At Risk
* Lost Customers
* New / Promising
* Big Spenders
* Potential Customers

## Dashboard

The Tableau dashboard presents:

* Total Customers
* Total Sales
* Total Orders
* Average Monetary Value
* Customer Segment Distribution
* Segment-wise Revenue
* Recency and Frequency Analysis
* RFM Segment Performance

## Outcome

The analysis helps identify high-value customers, customers at risk, and potential opportunities for retention and targeted marketing.
